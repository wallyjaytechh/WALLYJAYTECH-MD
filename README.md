## 🛠️ Installation Guides

### 🖥️ Local (Windows / Linux / macOS)

```bash
# Prerequisites: Node.js 18+, Git, FFmpeg
git clone https://github.com/wallyjaytechh/WALLYJAYTECH-MD.git
cd WALLYJAYTECH-MD
npm install
node start.js
```

### 📱 Termux (Android)

```bash
pkg update && pkg upgrade -y
pkg install nodejs git ffmpeg -y
git clone https://github.com/wallyjaytechh/WALLYJAYTECH-MD.git
cd WALLYJAYTECH-MD
npm install
node start.js
```

### 🎛️ Panel (Katabump / Bot Hosting)

```bash
1. Fork repository on GitHub
2. Download the fork as ZIP
3. Upload ZIP to your panel
4. Unarchive the ZIP
5. Move all files to container root (../)
6. Run: node start.js
7. Enter your WhatsApp number
8. Enter the 8-digit pair code in Linked Devices
9. Done — use .menu to test
```

## ⚙️ Environment Variables

| Variable | Required | Description |
|:---|:---:|:---|
| `SESSION_ID` | ❌ | Pre-generated session (skip pairing) |
| `PREFIX` | ❌ | Command prefix (default: `.`) |
| `TIMEZONE` | ❌ | Timezone (default: `Africa/Lagos`) |
| `OWNER_NUMBER` | ✅ | Your WhatsApp number |
| `BOT_NAME` | ❌ | Bot display name |
| `BOT_OWNER` | ❌ | Owner display name |
